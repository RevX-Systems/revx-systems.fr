REVX SYSTEMS — V3 : REPRISE FIDÈLE DE LA MAQUETTE
================================================

La version V3 corrige le prototype précédent :
- titres moins massifs et hiérarchie typographique resserrée ;
- rubriques et boutons plus visibles ;
- deux offres présentées sous forme de panneaux photographiques identiques ;
- bloc de fonctionnement horizontal illustré, avec panneau central sombre ;
- bandeau de réassurance compact, photographies et contact de fin de page ;
- visuel SSV / Alpes lumineux conservé ;
- logo original de la facture conservé.

OUVRIR LE SITE
Décompresser l'archive, puis ouvrir index.html dans un navigateur.
Le site est statique : aucune dépendance ni installation nécessaire.
Pour une prévisualisation via un serveur local :
  python -m http.server 8000
  puis http://localhost:8000

DOSSIER
index.html : page d'accueil
style.css : présentation desktop / tablette / mobile
script.js : navigation, menu mobile
assets/ : logo + photographies d'illustration
mentions-legales.html / confidentialite.html : textes à compléter

IMPORTANT AVANT MISE EN LIGNE
1. Les photographies de véhicules et de calculateurs sont provisoires.
   La photo du PC et du matériel de la solution REVX est un visuel conceptuel
   extrait de la maquette ; elle ne représente pas nécessairement un produit réel.
2. Le logo est extrait de la facture. Une source vectorielle originale serait idéale.
3. Le bouton de contact ouvre le logiciel e-mail (mailto), sans formulaire intégré.
4. Les pages légales et la politique de confidentialité sont des modèles incomplets.
5. Vérifier les textes de prestations, compatibilités et règles applicables avant publication.
6. La page actuelle www.revx-systems.fr n'a pas été modifiée.

Le fichier REVX-apercu-v3-autonome.html fourni à part contient la landing page
et ses visuels intégrés ; il permet une consultation sans extraire l'archive.
